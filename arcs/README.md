# Narrative Arcs

This directory contains **story arc files** for the Northwatch Wardens campaign — high-level throughlines that connect individual adventures into a coherent season-long narrative.

---

## What Is a Story Arc?

A story arc is the macro-level shape of a narrative: the dramatic question, the key beats, the characters who drive it, and the consequences of its resolution. Arc files complement individual adventure modules by tracking the *through-line* across sessions.

Arc files are **DM-facing** by default. They may reference player-safe content, but the arc overview itself contains spoilers.

## How to Use These Files

- **Before a session:** Review the relevant arc beat to understand where you are in the story.
- **After a session:** Update the "Status" column in the Scenes table to reflect what happened.
- **When planning new content:** Check the revelation ladder before adding new clues to avoid over-revealing or contradicting earlier beats.
- **When adapting:** Use the "Adaptations" section to find guidance if players go off-script.

---

## Creating a New Arc

1. Copy [`../templates/Story_Arc_Template.md`](../templates/Story_Arc_Template.md)
2. Name the file `Season_X_Arc_Name.md`
3. Fill in all sections — at minimum: Overview, Dramatic Question, Scenes, Key Characters, Revelation Ladder
4. Add an entry to the table above
5. Link the arc file from any relevant adventure files and the Season campaign dashboard
