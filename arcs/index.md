# Narrative Arcs

Season-spanning throughlines that connect individual adventures into a coherent narrative. Arc files are DM-facing — they contain spoilers and revelation sequences.

## How to Use

- **Before a session:** Review the current arc beat to know where you are in the story
- **After a session:** Note what changed — which beats were hit, what was revealed
- **When adding content:** Check the revelation ladder before planting new clues to avoid over-revealing or contradicting earlier beats
- **When adapting:** Use the Adaptations section to find guidance if players go off-script

## Creating a New Arc

1. Copy `../adventures/_template.md` as a starting point
2. Name the file `Season_X_Arc_Name.md`
3. Fill in: Overview, Dramatic Question, Key Beats, Key Characters, Revelation Ladder
4. Add an entry to the table above
5. Link from relevant adventure files
