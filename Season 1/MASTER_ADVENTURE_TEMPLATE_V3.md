## TEMPLATE USAGE NOTES

### For New Adventures (Phase 2+)

1. Copy this template
2. Replace [bracketed sections] with content
3. For scenes: use Scene 1 structure as template; repeat for each scene
4. Ensure all sections filled (don't skip sections unless explicitly optional)
5. Verify cross-links to Chapter 4 (prep tools) and Chapter 6 (secrets)
6. Test readability: can a DM use this to run a session after reading once?

### For Existing Adventures Being Standardized

1. Audit existing adventure for template fit
2. Extract content into template sections
3. Create missing sections (especially "Scaling" and "Consequences")
4. Verify readability after restructuring
5. Add cross-links to Chapter 4 and 6
6. Update table of contents

### Quality Checks Before Completion

- [ ] All sections completed (none left as [bracketed placeholders])
- [ ] Stat blocks are accurate and complete
- [ ] Read-aloud text is evocative but concise (2-3 sentences max)
- [ ] All scenes have decision points or consequences
- [ ] Scaling is specific (not generic advice)
- [ ] Cross-references point to correct materials
- [ ] Table of contents matches actual sections
- [ ] DM can run this after single read-through
