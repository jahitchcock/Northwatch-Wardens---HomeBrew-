## Standardization Workflow

### Step 1: Audit Individual Adventure
For each adventure:

1. **Copy existing adventure to new standardized folder**
2. **Extract Quick Reference data:**
   - Note adventure title, levels, sessions, themes
   - Count combat encounters, social encounters
   - Identify mystery rating (1-5 stars)
   - Identify core consequence
   - List key NPCs (3-5 main ones)
3. **Identify all scenes:**
   - Count total scenes
   - Map scene sequence
   - Note major decision points
4. **Extract scaling information:**
   - Find existing party-size notes
   - Identify which encounters scale, which are fixed
   - Note difficulty scaling approach
5. **Identify gaps:**
   - Missing prep checklist? Create one
   - Missing common questions? Identify and answer
   - Missing maps/handouts? Note them
   - Missing consequence tracker? Identify decision branches

### Step 2: Map to Template Structure

Using Master Adventure Template v3, create outline:

```
Quick Reference Card ← Extract from adventure
Adventure Overview ← Existing content (reorganize)
Running This Adventure ← Create if missing, expand if minimal
Scenes 1-X ← Existing scenes (reformat if needed)
Scaling for Party Size ← Create or expand
NPC & Monster Stat Blocks ← Extract from adventure
Magic Items & Treasure ← Extract or create
Consequences & Aftermath ← Extract and organize
Common Questions & Tips ← Create from DM experience
Appendix ← Compile maps, handouts, tables
```

### Step 3: Standardize Formatting

For each adventure being standardized:

**Section Headers:**
- Ensure consistent H1/H2/H3 hierarchy
- Match formatting style to Master Template example

**Read-Aloud Text:**
- Verify it's 2-3 sentences max
- Check for sensory-first structure
- Ensure atmospheric tone

**Stat Blocks:**
- Verify complete (AC, HP, abilities, actions, tactics)
- Ensure consistent formatting across all stat blocks
- Link descriptions to Quick Reference Card
- Add "How They Fight" and "Treasure" sections if missing

**Consequences:**
- Organize by major decision point
- Include immediate/short-term/long-term impacts
- Note affected NPCs
- Update Campaign Tracker instructions

**Scaling:**
- Create explicit scaling table for each combat encounter
- Provide specific adjustments (not generic advice)
- Include scaling philosophy note

**Cross-References:**
- Every adventure references Chapter 4 for prep support
- Every adventure references Chapter 6 for secrets
- Every scene links to relevant NPC details

### Step 4: Create Supporting Materials

For each adventure:

- **Quick Reference Card** (1 page, printable)
- **Prep Checklist** (printable checkbox list)
- **Scaling Table** (for combat encounters, if not already present)
- **Consequence Tracker** (decision tree for world changes)

### Step 5: Quality Review

Before finalizing:

1. **Readability Check:** Can DM run the adventure after reading once?
2. **Completeness Check:** Are all template sections filled?
3. **Cross-Reference Check:** Are all Ch 4/6 links valid and accurate?
4. **Formatting Check:** Does adventure match Master Template formatting?
5. **Tone Check:** Is adventure voice consistent throughout?
6. **Scaling Check:** Are scaling adjustments specific and implementable?
7. **Consequence Check:** Are decision branches clear and trackable?

## Specific Template Sections to Ensure

### Quick Reference Card (Must Have)
Required fields (all adventures):
- Adventure Title
- Levels & Sessions
- Themes (3-4)
- Mystery Rating (★☆☆☆☆ to ★★★★★)
- Type (Investigation/Combat/Social/Exploration/Hybrid)
- Key NPCs (3-5)
- Core Consequence (one sentence)
- Echo Manifestation (how Echo appears)

### Running This Adventure (Must Have)
Required sections:
- Preparation Checklist (must-prep vs. should-prep)
- Pacing Overview (session breakdown if multi-session)
- Pacing Notes (where to watch timing)
- Common Pacing Issues & Solutions (2-3 items)

### Scaling for Party Size (Must Have)
Required for ALL adventures:
- For 2 Players: [how to adjust]
- For 3 Players: [baseline]
- For 4-5 Players: [how to adjust]
- Scaling Philosophy: [1-2 sentences explaining approach]

### Consequences & Aftermath (Must Have)
Required:
- Core Consequence (world-changing impact)
- Secondary Consequences (organized by decision path)
- Things to Remember (checklist for future sessions)
- Campaign Tracker Update (what to note)

## Specific Guidelines for Each Adventure

### Wolves of Welton

**Unique Structure:** Council vote creates permanent consequence branch

**Scaling Approach:** "Wolf encounters scale by number; use 2-3 for small parties, 4-5 for large"

**Key Consequence Branches:**
1. Allies with wolves (Bolt helps in future adventures)
2. Kills all wolves (closing of one consequence path)
3. Compromise solution (wolves relocate but remain allies)

**Quick Ref Template Data:**
- Levels: 1-3
- Sessions: 3-4 (4-6 hours)
- Type: Investigation with Combat
- Mystery ★★★★★ (inciting incident)
- Kind NPCs: Bolt, Father Merriksonn, Westly, Tillus, Brenna

### Frozen Sick

**Unique Structure:** Multi-encounter puzzle exploration combat

**Scaling Approach:** "Salsvault fights scale by adjusting spore mechanics; fewer clouds for small party, harsher for large"

**Key Consequence Branches:**
1. Seals Salsvault (temporary solution)
2. Leaves Salsvault active (ongoing threat)
3. Brings artifact back (attracts factions)

**Quick Ref Template Data:**
- Levels: 2-4
- Sessions: 3-4 (revelation adventure)
- Type: Exploration + Environmental Survival
- Mystery ★★★★★ (revelation)
- Key NPCs: Pelc, Tulgi, Urgon, Elro, Boss entity

### Temple of the Dragonknights

**Unique Structure:** Multiple faction paths, dragon encounter, escalating challenges

**Scaling Approach:** "Adjust number of cultists and dragon HP; combat can range from 1-4 fights depending on party choices"

**Key Consequence Branches:**
1. Dragon dies in combat (catastrophic regional impact)
2. Dragon escapes (ongoing threat)
3. Dragon enslaved (faction control)
4. Alliance with dragon (most uncommon, most complicated)

**Quick Ref Template Data:**
- Levels: 4-5
- Sessions: 4-5 (capstone adventure)
- Type: Combat + Infiltration + Social
- Mystery ★★★★☆ (answers what comes next)
- Key NPCs: Cult Leader, Dragon, Faction representatives, Dragonknights ghost

### Wild Sheep Chase

**Unique Structure:** Comedy adventure, reduced mechanical complexity, emphasis on chaos

**Scaling Approach:** "Party size less important than flexibility; scale by how many magical creatures are active at once"

**Key Consequence Branches:**
1. Sheep contained (Noke loses spell research)
2. Sheep escape into Northreach (ongoing joke, minor consequences)
3. Players polymorphed (tactical chaos)

**Quick Ref Template Data:**
- Levels: 1-2 (actually flexible, fun even at 1st level)
- Sessions: 1-2 (2-3 hours)
- Type: Comedy Magical Chaos
- Mystery ★★★☆☆ (shows magical instability)
- Key NPCs: Noke, Sheep, Flora the Ranger, Finethir

### Peril in Pinebrook

**Unique Structure:** Investigation with multiple faction interests

**Scaling Approach:** "Bandit encounters scale; use 2-4 bandits depending on party size. Town politics less affected by party size."

**Key Consequence Branches:**
1. Bandits defeated militarily (town secure, bandit lord escapes)
2. Bandits negotiated with (compromise solution)
3. Bandits absorbed into town (most complex, ongoing relationship)

**Quick Ref Template Data:**
- Levels: 1-3
- Sessions: 2-3 (1.5-3 hours)
- Type: Investigation + Negotiation
- Mystery ★★★☆☆ (frontier fragility)
- Key NPCs: Bandit leader, Town council, Merchants, Refugees

### Opening Adventures (Treat as Unit)

**Unique Structure:** Three interconnected opening scenarios

1. **Open Skirmish** — Combat encounter (wolves on road)
2. **The Morning After** — Social setup (guild introduction)
3. **Wolves - Contract** — Briefing (first mission)

**How They Connect:**
- Open Skirmish happens on journey to Waystone
- Morning After is arrival and settling in
- Wolves Contract is first guild mission briefing
- Together: 1 full session or spread across 2

**Scaling:** "All three scale together as intro sequence. Keep encounters moderate; let players feel confident before scaling."

**Quick Ref Template Data (Unit):**
- Levels: 1-2
- Sessions: 1-2 (4-6 hours combined)
- Type: Combat + Social + Briefing
- Mystery ★☆☆☆☆ (introduction only)
- Key NPCs: Veteran allies, Guild leadership, Wolves (hint of future)

## Versioning & Update Strategy

**Before Phase 2.1 Lock:**
- Save original adventures as backup (folder: "Adventures/BACKUP_ORIGINALS")
- Create new standardized versions in main adventure folders
- Don't delete originals until standardized versions QA'd

**Versioning Notation:**
- Original: `5E_Wolves_Of_Welton.md` (keep as backup)
- Standardized: `Wolves_Of_Welton_V3.md` (new standardized version)
- Or: Refactor in place if confident

**QA Process:**
1. Create standardized version
2. Test readability (can new DM use it?)
3. Verify all template sections present
4. Check cross-references
5. Compare to original (ensure nothing lost)
6. Green-light for Phase 2.3+ use
