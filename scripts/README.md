# Scripts Directory

This folder separates actively used automation from historical one-off utilities.

## Active Scripts

- `build/add_page_footers.py` - Build-time footer updater invoked by `build.js`.
- `sync/sync_homebrew_to_sources.py` - Homebrewery export back-sync helper.
- `powershell/build-players.ps1` - Optional PowerShell helper for player guide build.

## Archived Scripts

- `maintenance/archive/` - Legacy ad-hoc diff, cleanup, and quote-fix scripts.
- `sync/archive/` - Prior sync experiments and superseded sync variants.
- `powershell/archive/` - Temporary or one-off PowerShell scripts.

Use archived scripts for reference only unless intentionally revived.
