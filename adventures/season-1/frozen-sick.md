The pivotal revelation adventure of the Northwatch Wardens campaign. A magical disease — frigid woe — is turning villagers in Palebank into ice statues. The only cure lies in Salsvault, a buried Aevorian laboratory that recently reactivated and is the source of all the campaign's prior magical disturbances. This is the adventure that answers every question the campaign has been building toward.

**Original Module:** *Frozen Sick* from Explorer's Guide to Wildemount (source module, adapted for this campaign)  
**Campaign Adaptation:** *The Pale Sickness* — fully integrated with Northwatch Wardens NPCs, Aevorian Echo arc, and Northreach setting

**Use this file if:** You need to reference the original module name for cross-referencing purposes.  
**Run from this file:** `the-pale-sickness.md` — that file contains the full table-reader content.
