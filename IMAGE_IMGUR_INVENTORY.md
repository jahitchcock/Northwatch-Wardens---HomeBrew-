## Upload Instructions

### Step 1: Prepare Images
1. Create imgur account if needed (https://imgur.com)
2. Download all images from file paths listed above
3. Optionally: batch upload to create an imgur album

### Step 2: Record imgur URLs
As each image is uploaded, record its imgur URL in the format:
```
Original: ./Path_To_File/image_XXX.png
Imgur URL: https://i.imgur.com/[CODE].png
```

### Step 3: Replace in Source Files
Use imgur URLs to replace relative paths in each markdown file:
```markdown
# OLD (relative path)
![Description](./5E_Wolves_Of_Welton_images/image_001.png)

# NEW (imgur direct link)
![Description](https://i.imgur.com/[CODE].png)
```

### Step 4: Rebuild
After all replacements:
```bash
npm run build:dms
```
