# Player Lore

This directory is the **index of all player-safe lore** in the Northwatch Wardens campaign. Content here is cleared for players to read freely.

> **For DMs:** Do not put spoilers or DM-only content in this directory. Player-safe content is stored in `World Building/` (non-DMEyesOnly subdirectories). This index points to those canonical files.

---

## What Is Player-Safe?

Player-safe content is information that:
- A player character would plausibly know or be able to learn through in-world means
- Does not spoil plot reveals, NPC secrets, or the Aeorian Echo mystery
- Can be shared at the table without breaking immersion or undermining discoveries
