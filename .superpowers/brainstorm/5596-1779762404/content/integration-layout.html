Where should the PDF library live?

How the rulebook viewer integrates into the existing dashboard at localhost:5050

A

Dedicated top-level tab

A "Rulebooks" tab in the main nav alongside NPCs, Characters, etc. Full-screen PDF experience — library sidebar on the left, reader on the right. Feels like its own app within the dashboard.

[Files] [NPCs] [Characters] [Rulebooks] [Calendar] [Tools ▾]
B

Tools dropdown entry → opens modal/overlay

PDF viewer launches as a full-screen modal from the existing "Tools" dropdown. Keeps the nav clean. Easy to access mid-session without leaving your current file.

[Files] [NPCs] [Characters] [Calendar] [Tools ▾]
                                                    ↳ 📖 Rulebooks
C

Separate browser tab / standalone route

The server adds a /rulebooks route that opens in a new tab. Fully independent of the main dashboard — you can have both open side-by-side. No nav clutter, maximum screen real estate for the reader.

localhost:5050   |   localhost:5050/rulebooks ← new tab
