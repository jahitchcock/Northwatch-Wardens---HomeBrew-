How it works

  • Effect buttons toggle — active effects are highlighted, inactive are dimmed. Multiple can be on simultaneously (e.g. rain + darkness for a stormy night).
  • Darkness slider — independent of the effect buttons, ranges 0–100%, updates live on the VTT screen.
  • All changes push instantly via the existing WebSocket — no page refresh on the VTT screen.
  • Effects are CSS animations on the VTT screen — rain (diagonal streaks), fog (drifting layers), snow (falling particles), fire (warm pulsing glow at bottom). Lightweight, no canvas, no libraries.
  • "Clear Effects" resets all toggles and darkness to zero in one click.
  • "Open VTT" opens /vtt in a new tab (convenience shortcut).
