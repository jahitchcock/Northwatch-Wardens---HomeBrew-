# Scratchpad

This directory is the **unstructured idea space** for the Northwatch Wardens campaign. Anything goes here — raw fragments, half-formed concepts, transcripts, sketches, early drafts, and notes not yet ready for canon.

---

## Philosophy

> *Write fast, think later.*

The scratchpad exists so that good ideas don't get lost waiting for the "right moment" to document them properly. Drop ideas here whenever they surface. Promote them to structured lore files when they're ready.

---

## How to Use

1. **Create a file** named for the topic or date (e.g., `2026-03-25_session_ideas.md`, `npc_fragment_bounty_hunter.md`).
2. **Write freely** — no template required, no formatting standards.
3. **Mark the status** at the top of the file so future-you knows what to do with it:

```
Status: Raw idea — not canon
```

4. **Promote when ready:** Once an idea is developed enough, move it to the proper directory using the appropriate template from [`/templates/`](../templates/).

## Promotion Checklist

When promoting a scratchpad entry to canon:

- [ ] Copy the appropriate template from `/templates/`
- [ ] Fill in the metadata header (Tags, Status, Type, Region, Linked)
- [ ] Move the file to the correct content directory
- [ ] Add internal links from the new file to related existing files
- [ ] Add a link from related existing files back to the new file
- [ ] Update this scratchpad index (remove or archive the promoted entry)

---

## Notes

- Nothing in this folder is considered canon unless explicitly promoted.
- DM-only ideas should still be prefixed with a `DM:` note at the top.
- This folder is tracked in git, so even raw notes are version-controlled.
- The older `World Building/Scratchpad.md` serves as an index to promoted content in `World Building/` — this `/scratchpad/` folder is the unstructured intake zone.
