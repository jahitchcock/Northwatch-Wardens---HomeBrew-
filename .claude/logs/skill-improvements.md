# Skill Improvement Log

Recommendations generated by `skill-self-review` during agentic runs. Review periodically and implement approved changes via interactive mode.

| Column | Meaning |
|--------|---------|
| Date | ISO date of the run that generated the recommendation |
| Skill | Which skill was reviewed |
| Status | `Pending` / `Implemented` / `Rejected` |

Update **Status** manually after acting on an entry.
